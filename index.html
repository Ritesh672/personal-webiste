02 · How I build

Inside my research agent

A question goes in, the agent plans its own steps, picks tools, retrieves evidence and returns a structured answer, keeping memory between turns.

  1. 1QuestionOpen-ended research query
  2. 2PlanBreak it into steps
  3. 3Pick a toolTool calling across 5+ tools
  4. 4RetrieveRAG over embeddings
  5. 5AnswerStructured response via FastAPI
